# Scientific Method Lab

Apply `.agents/skills/learning-design/SKILL.md` and `.agents/skills/ux/SKILL.md`
before and after changes. Keep `npm run check` green. Lessons have one main
observable outcome, a small complete example, a change to try, and a fresh
application with explanatory feedback. Explain terms before use. Keep lessons
short; split a second teaching objective into another lesson.

Never invent execution output. The build runs every Python example to produce
worked output and figures. Label invented and simulated data at point of use.
Keep independent experimental units distinct from repeated readings. State the
assumptions and target quantity of inference methods. Preserve self-hosted,
pinned Python assets, relative Pages paths, keyboard access, error recovery,
local drafts and portable exports. Reading marks and successful runs are separate.
Record sources, review findings, tests and evidence gaps in `docs/review.md`.
